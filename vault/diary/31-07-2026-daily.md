# Daily — 31-07-2026

## Resumo
Fechei o problema do datamapping do Agent V2 que quebrava com Anthropic e OpenAI: recuperei o documento do diagnóstico, confirmei que ainda não estava corrigido e apliquei a solução usando o id do próprio custom field como chave técnica válida nos dois lados (geração do schema e leitura da resposta). Depois fui para o front: reformatei os campos personalizados da sidebar do livechat em linhas empilhadas, normalizei as mensagens de erro do NestJS (array → string) e trabalhei bastante a validação do formulário de agentes com Zod/Vee — efeito visual de validação, bloqueio do submit no "Concluir edição", `systemPrompt` obrigatório só no modo advanced e o novo step de base de conhecimento.

## O que fiz
- **08:21–08:57** — Recuperação do doc do bug do datamapping, confirmação de que não estava corrigido e correção usando o id do custom field como chave técnica (definições + executor + testes da tool) _(chatfunnel-api)_
- **09:25–09:38** — Reformatação dos campos personalizados da sidebar do livechat em linhas empilhadas com scroll interno; descrições de PR para front e api _(chatfunnel-front)_
- **14:16** — Normalização das mensagens de erro do NestJS (array → join `", "`) no `common/api/index.js` _(chatfunnel-front)_
- **14:29–14:54** — Validação do formulário de agentes com Zod/Vee: efeito visual do `VeeInput`, alinhamento do `ImageGroupsStep` e bloqueio do submit para que "Concluir edição" passe pelo Zod _(chatfunnel-front)_
- **15:00** — Adição do step de base de conhecimento na criação do agente avançado _(chatfunnel-front)_
- **15:25** — `systemPrompt` tornado obrigatório só no modo ADVANCED no schema Zod _(chatfunnel-front)_

> [!tip] Decisoes
> - Usar o id do próprio custom field como chave técnica do datamapping (`customFieldId String? @db.Uuid`, `onDelete: SetNull`, sem constraint de unicidade), aplicada de forma determinística nos dois lados.
> - `systemPrompt` obrigatório apenas no modo ADVANCED (prompt direto só existe nesse modo).
> - Base de conhecimento vira um step da criação do agente avançado.
> - Normalizar `message` em array (validações do NestJS) juntando os itens com `", "` antes do toast; string continua igual.

> [!warning] Bloqueios
> - Bug do datamapping do Agent V2: o nome cru do campo era usado direto como chave e Anthropic/OpenAI rejeitavam por não bater o pattern (corrigido).
> - "Concluir edição" não passava pelo Zod, deixando passar grupos de imagem com descrição vazia (corrigido com bloqueio do submit).
