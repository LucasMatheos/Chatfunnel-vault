> [!tip] Decisoes
> - **Renderer registry**: nao fazer componente por tool MCP (50+ tools = 50 componentes mortos). Usar registry com fallback generico.
> - **Intelligence rewrite**: esquecer componentes existentes, refatorar do zero em `view/intelligenceV2`. Legacy e MVP nao usado em producao.
> - **Nao manter Intelligence antigo**: sem manutencao, sera substituido pelo v2.
> - **shadcn-vue**: usar como base de componentes UI para Intelligence v2.
> - **Backend gerencia estado**: frontend nao gerencia estado do chat diretamente.
> - **Templates Fase C**: alto risco por serem entidade Meta-side, executados por ultimo no playbook.
> - **Plano antes de codigo**: so montar arquitetura e guia, sem criar componentes ainda.

> [!warning] Bloqueios
> - **Silent-fail catastrofico no CRM**: mutacoes (create_kanban_card, move, win, lose, assign) persistem no banco mas MCP retorna erro. Bug em producao.
> - **MCP nao expoe galeria de media**: endpoint `api/medias` existe mas nao tem tool MCP correspondente. Impossivel listar mediaIds.
> - **MCP follow_up incompleto**: `answerStepId` e `unanswerStepId` nao sao configurados via `add_step_follow_up`. Gap de API.
> - **Template REJECTED pela Meta**: template de teste rejeitado quase imediatamente. 4 bugs novos encontrados no fluxo de templates.
