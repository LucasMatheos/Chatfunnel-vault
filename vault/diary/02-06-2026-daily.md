# Daily — 02-06-2026

## Resumo
Dia inteiro no Intelligence V2, em torno da troca dos "thinking labels" para um comportamento mais alinhado ao Claude Web. Escrevi o plano, movi as labels das tools para o `@chatfunnel/contracts`, sincronizei manualmente para o front e implementei. Boa parte da tarde foi debug: o pill mostrava só "Pensando..." independente da tool (dois bugs juntos), além de experimentos de suavização do streaming que acabaram revertidos. Fechei com ajuste no `ChatInput` para que selecionar uma tool no modal apenas escreva o prompt no input, sem enviar direto.

> [!tip] Decisoes
> - As labels das tools passam a viver no `@chatfunnel/contracts` (fonte única), não hardcoded no front.
> - Selecionar uma tool pelo modal apenas preenche o input — não envia direto, pois alguns prompts exigem dados do usuário.
> - `tool_status` com `status: 'running'` é ignorado para o pill não trocar instantaneamente.

> [!warning] Bloqueios
> - Sync manual de contracts → front é obrigatório antes do front enxergar as novas exports.
> - Vite serviu uma versão antiga do pré-bundle (`node_modules/.vite/deps/...`) sem `TOOL_LABELS`; causa era cache do pré-bundle, não o pacote.
